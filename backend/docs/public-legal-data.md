## 本次采集与整理结果

本机数据目录：`/Users/xiaoqi/law-data/win-rate-calibration/`。原始包、来源清单、候选正文和报告均位于此目录，目录权限 700、文件权限 600；仓库只保存准备脚本、合成测试与本文档。

| 产物 | 位置（相对数据目录） | 状态 |
| --- | --- | --- |
| 原始数据及来源清单 | `raw/msjudge/` | 固定作者版本，保留下载地址与校验值 |
| 500 条研究候选 JSONL | `cleaned/msjudge-research-candidates.jsonl` | 待人工隐私、泄漏和适用性复核，全部 `calibration_eligible=false` |
| 全量质量报告 | `reports/msjudge-quality.json`、`reports/msjudge-quality.md` | 实测计数、字段覆盖、过滤原因与限制 |
| 时间划分状态 | `splits/manifest.json` | 缺少裁判日期及复核，未生成拟合/测试数据 |
| 校准参数 | `params/` | 预留空目录，未拟合参数 |

所有记录仅有 `court_debate`、`fact_description`、`claims`、`claims_labels`、`roles`、`fact_labels` 六个字段。**裁判日期、审理程序、法院级别、省份、被告缺席、结案方式以及请求/支持金额均无独立字段**。辩论中出现的借款日期不能代替裁判日期；“调解”“缺席”等提及也不能当作结案或到庭事实。因此正式校准合格样本目前为 **0 案**，不能按要求完成时间切分验证。

作者代码明确区分 `Support`、`Partially Support`、`Reject`（见固定版本 [train.py](https://github.com/mly-nlp/LJP-MSJudge/blob/87f038e714f3bac4e8bee461983715f8893261db/train.py#L439)），实测逐项诉求标签为 100,110 / 24,028 / 9,076 项。准备脚本对应保存为 `fully_supported` / `partially_supported` / `dismissed`，不把部分支持转为 0.5，也不据此生成“主要本金获支持”的整案 `case_win` 或金额。

本次候选处理：

1. 全量扫描结构与字段；排除诉求/标签无效、多项诉求、缺少双方发言、角色与发言不对齐的记录。多项诉求的整案合并口径留待定义。
2. 只保留 `claims` 和 `roles` 为“原”“被”的发言；法官/其他发言、`fact_description` 和 `fact_labels` 不进入输入。包含“本院认为”“判决如下”“经审理查明”等标记的记录保守隔离。
3. 按输入哈希去重，相同输入若标签冲突则隔离；从 15,927 条唯一研究候选中按固定哈希顺序抽取 500 条，保留来源编号和处理版本。选中标签分布为完全支持 411、部分支持 77、驳回 12；这是筛选后的研究子集，不是产品案件胜率。
4. 使用规则遮蔽邮箱、手机号和长数字标识；500 条中 354 条触发遮蔽。姓名、地址及残留裁判内容仍需人工复核，不能声称已完成脱敏或消除泄漏。
5. 标准化 JSONL 的日期、程序、地域、缺席、结案方式、金额和 `case_win` 保持 `null`，不编造缺失字段。全部标注研究候选及待复核原因，不接入线上校准。

复现准备流程（已有固定版本原始包与来源清单时）：

```sh
cd backend
.venv/bin/python scripts/prepare_msjudge.py \
  --data-root /Users/xiaoqi/law-data/win-rate-calibration --sample-size 500
```

脚本使用 Python 标准库流式读取 ZIP 内 JSON，避免将约 621 MB 解压文本整体载入内存；会拒绝仓库内数据目录，并重新核验原始包与版本。合成用例覆盖分块读取、截断/重复记录、泄漏隔离、未知元数据、标签及标识遮蔽。

## 查询公开与批量复用的区别

[人民法院案例库用户协议](https://rmfyalk.court.gov.cn/useragreement.html)第 3.1 条允许经注册授权后查询、学习和研究，同时限制超出用户权限及合理使用范围的传播或盈利行为，包含汇编、镜像和数据库交易等；第 3.3 条要求不得干扰网站正常运转。本次未发现该平台正式开放的批量训练数据下载渠道，不能把网页公开视为可自由抓取、建库及商用的授权。

[人民法院案例库建设运行工作规程](https://www.court.gov.cn/fabu/xiangqing/431662.html)规定参考案例经审核且具有示范价值，同一具体法律适用问题一般不超过两件，因而不能直接用检索结果的胜诉占比推断本案概率。
