## 查询公开与批量复用的区别

[人民法院案例库用户协议](https://rmfyalk.court.gov.cn/useragreement.html)第 3.1 条允许经注册授权后查询、学习和研究，同时限制超出用户权限及合理使用范围的传播或盈利行为，包含汇编、镜像和数据库交易等；第 3.3 条要求不得干扰网站正常运转。本次未发现该平台正式开放的批量训练数据下载渠道，不能把网页公开视为可自由抓取、建库及商用的授权。

[人民法院案例库建设运行工作规程](https://www.court.gov.cn/fabu/xiangqing/431662.html)规定参考案例经审核且具有示范价值，同一具体法律适用问题一般不超过两件，因而不能直接用检索结果的胜诉占比推断本案概率。

## 推荐下一步

1. 优先核实 MSJudge 数据使用许可、实际发布字段和标签，完成最小数据适配与质量报告；真实案件数据存放在仓库之外。
2. 选择一个明确的预测目标和适用阶段，排除裁判结果及未来信息泄漏，按案件分组去重并核查时间划分条件。
3. 比较固定基准概率与简单模型，独立验证预测和概率校准；先报告适用范围及误差，再决定是否将结果接到仪表盘。
4. 商用授权或分布适用性不满足时，只将该公开集作为研究候选，另行取得适合目标业务的数据。

公开数据使历史案件模型方案具备进一步研究的起点，但本次核查不等于数据授权、模型训练或胜诉概率验证已经完成。
